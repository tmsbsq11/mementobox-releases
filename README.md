# Memento Box

Downloads for Memento Box, a personal reference library for artists (Android phone + Windows / Linux PC, syncing over your own Wi-Fi).

Get the newest version from **[Releases](../../releases/latest)**:

- **Android:** `MementoBox-<version>.apk`
- **Windows:** `MementoBox_<version>_x64-setup.exe` (the first time Windows may say "unknown publisher": More info > Run anyway)
- **Linux:** `MementoBox_<version>_amd64.AppImage` (or the `.deb`)

Install once; after that the apps update themselves.
